## ✨ Hakkımda

Gerçek dünya projeleri geliştirerek hem backend hem frontend tarafında kendimi geliştiriyorum.

Şu an odaklandığım alanlar:
- ASP.NET Core Web API geliştirme
- Modern backend mimarileri
- Veritabanı tasarımı ve performans optimizasyonu
- Full stack proje geliştirme
